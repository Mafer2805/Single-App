//BMI Health Advisor es una aplicación desarrollada en Flutter que permite calcular el Índice de Masa Corporal (IMC) de una persona a partir de su peso y altura. La aplicación cuenta con una interfaz sencilla donde el usuario ingresa su peso en kilogramos y su altura en metros. Al presionar el botón **Calcular**, la app muestra el valor del IMC y una clasificación general del resultado: bajo peso, normal, sobrepeso o riesgo alto. Además, la aplicación valida los datos ingresados para evitar errores cuando los campos están vacíos o cuando se escriben valores decimales con coma. Cada clasificación se muestra con un color diferente para facilitar la interpretación del resultado. Este proyecto fue desarrollado como práctica para implementar conceptos básicos de flutter, como el uso de widgets, controladores de texto, manejo de estados y aplicación de entradas.
